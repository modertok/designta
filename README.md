# ThreadScope

Лендінг, демо вебзастосунку та макет розширення браузера для системи збору та статистичної обробки даних для аналізу контенту Threads (кваліфікаційна робота).

- `/#/` — лендінг
- `/#/app` — вебзастосунок з функціоналом (демо-дані): огляд, найкращий час, публікації, пошук, текст і тональність, статистика, експорт CSV/JSON, підключення (OAuth-імітація)
- `/#/extension` — дизайн розширення «ThreadScope Lens» (профіль, публікація, popup, принцип роботи)

Усі дані демонстраційні (детермінована генерація). Розрахунки (ER, кореляції Спірмена/Пірсона, Манна–Уітні, TF-IDF, теплова карта) виконуються в браузері за формулами з розділу 1 пояснювальної записки.

## Запуск

```bash
npm install
npm run dev      # розробка
npm run build    # збірка у dist/
```

## Публікація на GitHub Pages

Репозиторій має бути публічним. У Settings → Pages виберіть Source: **GitHub Actions** — після кожного push у `main` сайт збирається й публікується автоматично (`.github/workflows/deploy.yml`). Маршрутизація через `HashRouter`, шляхи `base: "./"`, тому сайт працює з будь-якою назвою репозиторію.
